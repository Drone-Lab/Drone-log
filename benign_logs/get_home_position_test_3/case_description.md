"thoughts": "The takeoff‑altitude logic in Mission::calculate_takeoff_altitude() always refers to the current home altitude when the vehicle is not landed. If the home altitude is ever updated mid‑flight (for example via a DO_SET_HOME command or a recalibrated GPS fix), calculate_takeoff_altitude() will return a different threshold for the minimum takeoff altitude than was used originally. That new threshold then feeds into Mission::do_need_vertical_takeoff(), which may suddenly decide that a vertical takeoff is ‘needed’ for the current waypoint even though the vehicle is already en route. In practice this can cause the system to insert—or skip—a takeoff command in the middle of a mission, disrupting the waypoint sequence."
